## Critical decisions (locked, do not relitigate)

- **Scheduler:** Vercel Cron API routes (NOT Inngest). Match the pattern in `app/api/cron/detect-anomalies/route.ts`.
- **Cron headroom:** Pro plan supports 100 jobs/project. After v1.5 we use 7 of 100. Verified 2026-05-07.
- **Aggregation strategy:** Pre-computed nightly into dedicated tables. NEVER on read.
- **Event emission:** Fire-and-forget with Sentry capture. Never block critical paths.
- **Retention:** Events 90 days. Daily metrics permanent. Cohort metrics permanent. Anomalies permanent until dismissed.
- **RLS pattern:** All new tables use `merchant_id IN (SELECT id FROM merchants WHERE user_id = auth.uid())`.
- **Widget config schema:** v2 — explicit `defaultW/H` + `minW/maxW/minH/maxH` + `iconColor`. NO `defaultSize` / `allowedSizes` (legacy v1).
- **Widget shell patterns:** All new widgets use sticky footer (`flex-1 min-h-0` body + `flex-shrink-0` footer) + `useSetWidgetHeaderLink` where a detail page exists + `useSetWidgetSubtitle` where dynamic context helps.
- **Theme tokens only:** No hex codes — use `bg-card`, `border-border`, `text-foreground`, `text-primary`, etc.
- **Quiet rollout for anomaly detection:** `anomaly_detection_enabled` boolean on merchants table, default `false`. Manually enable per merchant during weeks 1-3 to monitor false-positive rate.

If any of these become blockers during build, stop and surface — do not silently change.

Adds country/currency/timezone to merchants AND customers. Multiple v1.5 phases reuse this.

### 1.1 Database migration

```sql

  ADD COLUMN country_name TEXT,        -- "United States"

  ADD COLUMN country_code TEXT,        -- "AE", "US"
  ADD COLUMN country_name TEXT,        -- "United Arab Emirates"
  ADD COLUMN region TEXT,              -- "Dubai", "California"
  ADD COLUMN city TEXT;                -- "Dubai", "San Francisco"

CREATE INDEX idx_customers_country_code
  ON customers(merchant_id, country_code)
  WHERE country_code IS NOT NULL;
```

**Why these columns:**
- Country code on **merchant** → drives holiday calendar selection in anomaly detection
- Country/currency/timezone on **merchant** → used across reports, scheduled emails, multi-currency display in v2
- Country/region/city on **customer** → powers GeographicSpread widget

### 1.2 Capture during Shopify OAuth

### 1.3 Capture during customer sync

In Shopify customer payload handler:

### 1.4 Backfill scripts

`scripts/backfill_merchant_geo.ts`:
- For each merchant where `country_code IS NULL`: fetch `/shop.json`, write 4 fields
- Default to "US" / "USD" / "America/New_York" if Shopify call fails

`scripts/backfill_customer_geo.ts`:
- For each customer where `country_code IS NULL`:
  1. Check most recent order shipping_address
  2. If no order address, fetch from Shopify Customer API
  3. Update customer with geo fields
- Rate limit: 2 calls/sec (Shopify API limit)
- Run from admin panel button per merchant

```typescript
import { NextResponse } from "next/server";
import { Client } from "pg";
import { getActiveMerchants, calcAvgHealthScore, /* etc */ } from "@/lib/metrics/queries";
import { yesterday } from "@/lib/dates";

export const maxDuration = 300; // 5 min

export async function GET(request: Request) {
  // Verify cron auth header (matches existing detect-anomalies pattern)
  const authHeader = request.headers.get("Authorization");
  if (authHeader !== `Bearer ${process.env.CRON_SECRET}`) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const date = yesterday();
  const merchants = await getActiveMerchants();
  const results = [];

  // Process in batches of 5 to avoid overwhelming DB
  for (let i = 0; i < merchants.length; i += 5) {
    const batch = merchants.slice(i, i + 5);
    const batchResults = await Promise.all(
      batch.map((m) => computeMerchantDailyMetrics(m.id, date))
    );
    results.push(...batchResults);
  }

  return NextResponse.json({ processed: results.length, date });
}

async function computeMerchantDailyMetrics(merchantId: string, date: Date) {
  // Build the metrics object using lib/metrics/queries helpers
  const metrics = {
    avg_health_score: await calcAvgHealthScore(merchantId, date),
    // ... all other helpers ...
    aov: await calcAov(merchantId, date),
    pct_orders_with_discount: await calcDiscountUsageRate(merchantId, date),
  };
  const topCode = await getTopDiscountCode(merchantId, date);
  if (topCode) {
    metrics.top_discount_code_name = topCode.code;
    metrics.top_discount_code_usage_pct = topCode.usage_pct;
  }

  // Upsert via pg client (bypasses RLS — server context)
  // ...
}
```

```tsx
        </ResponsiveContainer>
      </div>
    </div>
  );
}
```

### 5.3 Fire-and-forget emit helper
`lib/events/emit.ts`:
```typescript
import { Client } from "pg";

export async function emitEvent(params: {
  merchantId: string;
  eventType: string;
  entityType?: string;
  entityId?: string;
  payload?: Record<string, any>;
}) {
  // Fire-and-forget. NEVER throws. NEVER awaited in critical path.
  try {
    const pg = new Client({ connectionString: process.env.DATABASE_URL, ssl: { rejectUnauthorized: false } });
    await pg.connect();
    await pg.query(
      `INSERT INTO events (merchant_id, event_type, entity_type, entity_id, payload)
       VALUES ($1, $2, $3, $4, $5::jsonb)`,
      [params.merchantId, params.eventType, params.entityType ?? null, params.entityId ?? null, JSON.stringify(params.payload ?? {})]
    );
    await pg.end();
  } catch (err) {
    // Never throw — events should NEVER break business logic
    console.error("[emitEvent] failed silently", err);
    // TODO Phase 6 Sentry: Sentry.captureException(err, { extra: params });
  }
}
```

### 6.2 Day-of-week baseline

`lib/anomalies/detector.ts`:
```typescript
const METRICS_TO_WATCH = [
  "avg_health_score",
  "revenue",
  "orders_count",
  "new_customers",
  "repeat_rate",
  "revenue_at_risk",
];

export async function detectAnomaliesForMerchant(merchantId: string, date: Date) {
  // Get last 8 weeks of daily metrics for the SAME day-of-week
  const dayOfWeek = date.getUTCDay();
  const sameDaySamples = await getDailyMetricsForDayOfWeek(merchantId, dayOfWeek, 8);

  // NEW MERCHANT GUARD: <14 days history → skip detection entirely.
  // Returning empty is intentional: better quiet than wrong.
  if (sameDaySamples.length < 4) return [];

  const todayMetrics = await getDailyMetricsForDate(merchantId, date);
  if (!todayMetrics) return [];

  // Determine threshold for this day
  const threshold = await determineThreshold(merchantId, date);
  if (threshold === null) return []; // snoozed

  const anomalies = [];
  for (const metric of METRICS_TO_WATCH) {
    const baselineValues = sameDaySamples.map((s) => s[metric]).filter((v) => v !== null);
    if (baselineValues.length < 4) continue;

    const baselineMean = mean(baselineValues);
    const baselineStd = standardDeviation(baselineValues);
    if (baselineStd === 0) continue;

    const sigma = Math.abs((todayMetrics[metric] - baselineMean) / baselineStd);

    if (sigma > threshold.value) {
      anomalies.push({
        merchant_id: merchantId,
        metric,
        current_value: todayMetrics[metric],
        expected_value: baselineMean,
        deviation_sigma: sigma,
        severity: sigma > threshold.value + 1 ? "high" : sigma > threshold.value + 0.5 ? "medium" : "low",
        description: generateDescription(metric, todayMetrics[metric], baselineMean),
        detected_for_day_of_week: dayOfWeek,
        detection_reason: threshold.reason,        // 'normal' | 'sale_detected' | 'public_holiday'
        threshold_used: threshold.value,
      });
    }
  }
  return anomalies;
}
```

### 6.3 Threshold layering

`lib/anomalies/threshold.ts`:
```typescript
type ThresholdResult = { value: number; reason: 'normal' | 'sale_detected' | 'public_holiday' } | null;

export async function determineThreshold(merchantId: string, date: Date): Promise<ThresholdResult> {
  const merchant = await getMerchant(merchantId);

  // 1. SNOOZED → skip entirely
  if (merchant.anomalies_snoozed_until && merchant.anomalies_snoozed_until > new Date()) {
    return null;
  }

  // 2. SALE DETECTED → 5σ
  const sale = await checkSaleDetected(merchantId, date);
  if (sale) {
    return { value: 5.0, reason: "sale_detected" };
  }

  // 3. PUBLIC HOLIDAY → 4σ
  const isHoliday = await checkPublicHoliday(merchant.country_code, date);
  if (isHoliday) {
    return { value: 4.0, reason: "public_holiday" };
  }

  // 4. NORMAL → 3σ
  return { value: 3.0, reason: "normal" };
}
```

### 6.4 Sale auto-detection

`lib/anomalies/sale-detector.ts`:
```typescript
/**
 * Detect if today is part of a sale period.
 * Need 2+ signals firing to confirm. Returns confidence score 0-1.
 *
 * COLD-START GUARD: If merchant has <14 days of baseline data, skip entirely
 * and return null. New merchants might experience their first 2-week sale
 * as false-positive anomalies — acceptable tradeoff vs broken detection.
 */
export async function detectSale(merchantId: string, date: Date) {
  const baseline = await getBaselineMetrics(merchantId, date, 14); // 14-day rolling avg
  if (baseline.daysOfData < 14) return null;

  const today = await getDailyMetricsForDate(merchantId, date);
  if (!today) return null;

  const signals: string[] = [];
  let signalCount = 0;

  // Signal 1: discount usage rate >2x baseline
  if (today.pct_orders_with_discount > baseline.pct_orders_with_discount * 2) {
    signals.push("discount_usage_2x");
    signalCount++;
  }
  // Signal 2: AOV <75% of baseline
  if (today.aov < baseline.aov * 0.75) {
    signals.push("aov_drop");
    signalCount++;
  }
  // Signal 3: order volume >2x baseline
  if (today.orders_count > baseline.orders_count * 2) {
    signals.push("order_volume_spike");
    signalCount++;
  }
  // Signal 4: new customers >2x baseline
  if (today.new_customers > baseline.new_customers * 2) {
    signals.push("new_customer_surge");
    signalCount++;
  }
  // Signal 5: single discount code on >40% of orders
  if (today.top_discount_code_usage_pct > 0.4) {
    signals.push("dominant_discount_code");
    signalCount++;
  }

  if (signalCount < 2) return null;

  // Confidence: each signal = +0.2, capped at 1.0
  const confidence = Math.min(1.0, signalCount * 0.2);

  // Persist to merchant_detected_sales (pending confirmation)
  await upsertDetectedSale(merchantId, date, signals, confidence);

  return { signals, confidence };
}
```
